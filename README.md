# 合成野生狗奶 · 实时提示版

基于 [Arland123/WildDogMilk](https://github.com/Arland123/WildDogMilk) 原版制作的放置辅助版。原游戏地址：https://arland123.github.io/WildDogMilk/ 。原作者的游戏名称、奶盒贴图和界面设计均保留来源。

## 使用方式

1. GitHub Pages 公开版：https://zxshm.github.io/wilddog-milk-hints/ ，无需登录账号。源码仓库：https://github.com/zxshm/wilddog-milk-hints 。原 Sites 入口已改为公开排行榜后端；直接打开它会跳回 GitHub 游戏。
2. Windows 本地运行：安装有 Node.js 时，双击 `启动游戏.cmd`，随后访问 `http://127.0.0.1:4173`。命令行也可运行 `node serve.cjs`。
3. 无需联网的简便方式：直接打开 `dist/index.html`。在文件协议下提示器自动使用分段计算兼容模式，性能可能不如本地服务器方式。

移动鼠标或手指瞄准，点击或松手投放。方向键瞄准，空格投放，R 重开，H 按当前有效提示投放。

首次打开会先准备奶盒图片、样式和计算脚本；短暂下载失败会自动重试，网络恢复后可继续加载，无需刷新整页。计算线程异常时自动恢复或转入同算法的兼容计算。排行榜兼容缺少新超时接口的手机内核。修复原因及故障注入验证见 [首次加载与手机榜单修复](首次加载与手机榜单修复.md)。

## 新增的提示功能

- 默认开启。奶盒落定后，根据当前局面的真实位置、角度、速度、大小和级别重新计算。
- 棋盘上的绿色虚线、箭头和浅色区域表示本步推荐投放横坐标，蓝线表示下一盒的预估投放位置；高风险建议改用红色。标线表示投放位置，不表示最终落地位置。
- 点击“按提示放置”执行一次推荐操作；也可以继续手动投放。
- 快速、标准、深入三档均联算当前盒与界面公开的下一盒。每个当前落点都先尝试下一盒的候选位置，再按两步结束后的局面排名，不再只给单步前三名搜索后续。
- 显示两步预计得分、合成次数、搜索组合数和耗时。下一盒的蓝线是预估：当前盒实际落定后，会用新局面重新计算。
- 每次投放、重开、切换精度或局势发生明显变化时，旧结果立即失效。一键放置不会使用过期提示。
- 关闭提示后可以按原版方式自由游玩。提示版最高分使用独立的本地存储键。

## 原版界面与规则

保留原版的主样式、主界面结构、11 张奶盒贴图、得分区域、下一盒预览、音效开关、重开按钮、棋盘背景、警戒线、合成顺序、粒子与音效。

宽屏在棋盘右侧放置小型提示面板，不压缩原棋盘。700 像素及以下的手机窗口使用紧凑横排工具栏、32 像素合成顺序条和加大的放置按钮，棋盘根据可见高度和安全区尽量放大，仍保留原来的宽高比例与物理规则。极矮窗口可纵向滚动，避免棋盘被挤压变形。排行榜奖杯按钮和结束时的提交入口沿用原配色与样式。尺寸对比及验证边界见 [手机布局优化](手机布局优化.md)。

## 共同排行榜与持续冲分

点击右上角奖杯直接查看全体玩家共用的玩家排行榜，完成一局后填写昵称提交。允许使用提示，页面只有一个玩家榜，没有榜单切换选项。每个浏览器身份仅展示最高成绩，最多展示前 50 名；同分先达到者靠前。清除浏览器存储会丢失自己的提交身份，但已经保存的公开成绩仍在。自动测试不参与玩家排名，历史测试成绩保留在验收记录中。

榜单记录保存于 Sites 托管的 Cloudflare D1，通过公开 API 读写。GitHub Pages 只提供页面，网页中不包含 GitHub 写入凭据或数据库密钥。昵称与分数公开。当前分数来自客户端上报，有格式、范围、身份、提交间隔和重复提交检查，但尚未实施服务端逐局回放验证，不能视为防作弊竞赛榜。

本地访问 `/__qa/plan?endless=1`，点击“开始自动验收”，即可在首次合成第 11 级后继续按提示投放，直到真实溢出结束。测试页有 5000 步、60 分钟保护上限，触及时会明确记录上限原因，不把截断当作自然结束。自动点击和显示加速只存在于本地验收页。物理规则不变；通关后仍完整计算两步与后续概率前瞻。技术实现与证据见 [排行榜与持续测试](排行榜与持续测试.md)。

逻辑坐标仍为 400 × 720，警戒线为 150。同级相碰合成、半尺寸生长、最高级爆炸、越线持续两秒结束等规则均使用原版参数。

## 计算原理与边界

`physics.js` 是实际游戏与预测器共用的物理内核。`solver.js` 对不同横坐标分别创建局面副本，推进 Matter.js 碰撞、旋转、合成与生长。第一盒落下后，在每个候选局面上继续模拟第二盒，比较两步最终的合成收益、堆叠高度、剩余盒子数量、运动和越线危险。

评分优先选择存活路线，并提高合成收益权重；表面平整度只占很弱的次要权重，没有“尽量横放”的直接奖励。候选除了均匀覆盖棋盘，还包含同级盒子的接触位置和倾斜支撑边缘，允许通过偏心碰撞推动和翻转盒子。搜索数量由精度档固定，设备速度影响等待时间，不再按耗时截断基础搜索或细化搜索。

优先在 Web Worker 中计算，避免阻塞游戏。仅使用当前盒子和界面公开的下一盒，不读取尚未生成的随机盒子。

物理快照保留接触点冲量、接触顺序、旋转轴、惯量、位置和速度，避免只复制几何形状造成的摩擦和翻倒预测偏差。对曾经失败的整局 289 步逐步重放，原局面与副本的合成得分全部一致，最大位置误差小于 `1e-7` 个游戏坐标单位。

提示仍是对有限候选和已知两盒的搜索，不构成对全部未来随机序列的必胜证明。实际落点误差、计算期间继续发生的运动以及未知后续盒子仍可能影响结果。“预计得分”不是承诺。完整对局验收与单元测试分开记录，不能用某一步预测正确代替通关验收。

```powershell

git subtree push --prefix dist github gh-pages
```

## 文件

- `dist/index.html`：原版主界面与新增提示控件。
- `dist/startup.js`：按依赖顺序加载脚本，准备和重试图片、样式，提供断网后继续加载入口。
- `dist/game.js`：原版绘制、音效、输入及物理内核连接。
- `dist/physics.js`：共享的物理和合成规则。
- `dist/solver.js`：候选模拟和下一盒前瞻。
- `dist/solver-plan.js`、`dist/solver-future.js` 和 `dist/layout.js`：当前正式入口的布局评价、两步备选与概率前瞻。
- `dist/hints-persistent.js`：正式入口的线程复用、过期结果校验及提示交互；发布版本沿主线程和分支线程传递，避免旧缓存混用。
- `dist/hints.js`：自动刷新、过期校验、标线及按钮。
- `dist/hint-worker.js`：后台计算入口。
- `dist/lib/matter.min.js`：原版 Matter.js 0.20.0，保留库中的 MIT 声明。
