# 合成野生狗奶 · 实时提示版

基于 [Arland123/WildDogMilk](https://github.com/Arland123/WildDogMilk) 原版制作的放置辅助版。原游戏地址：https://arland123.github.io/WildDogMilk/ 。原作者的游戏名称、奶盒贴图和界面设计均保留来源。

## 使用方式

1. GitHub Pages 公开版：https://zxshm.github.io/wilddog-milk-hints/ ，无需登录账号。源码仓库：https://github.com/zxshm/wilddog-milk-hints 。原个人私有站点仍保留：https://wilddog-milk-hints-20261022.zhangqiongxingzhe.chatgpt.site ，该入口需要登录所属账户。
2. Windows 本地运行：安装有 Node.js 时，双击 `启动游戏.cmd`，随后访问 `http://127.0.0.1:4173`。命令行也可运行 `node serve.cjs`。
3. 无需联网的简便方式：直接打开 `dist/index.html`。在文件协议下提示器自动使用分段计算兼容模式，性能可能不如本地服务器方式。

移动鼠标或手指瞄准，点击或松手投放。方向键瞄准，空格投放，R 重开，H 按当前有效提示投放。

## 新增的提示功能

- 默认开启。奶盒落定后，根据当前局面的真实位置、角度、速度、大小和级别重新计算。
- 棋盘上的绿色虚线、箭头和浅色区域表示推荐投放横坐标；高风险建议改用红色。它表示投放位置，不表示最终落地位置。
- 点击“按提示放置”执行一次推荐操作；也可以继续手动投放。
- 快速模式主要计算当前一步；标准和深入模式在时间预算允许时，比较若干最佳候选与已公开的下一盒。界面会标明本次是否考虑下一盒。
- 每次投放、重开、切换精度或局势发生明显变化时，旧结果立即失效。一键放置不会使用过期提示。
- 关闭提示后可以按原版方式自由游玩。提示版最高分使用独立的本地存储键。

## 原版界面与规则

保留原版的主样式、主界面结构、11 张奶盒贴图、得分区域、下一盒预览、音效开关、重开按钮、棋盘背景、警戒线、合成顺序、粒子与音效。

宽屏在棋盘右侧放置小型提示面板，不压缩原棋盘；窄屏在合成顺序条下增加提示控件，适当缩小棋盘以适应屏幕高度。除提示控件与推荐线外，不重新设计 UI。

逻辑坐标仍为 400 × 720，警戒线为 150。同级相碰合成、半尺寸生长、最高级爆炸、越线持续两秒结束等规则均使用原版参数。

## 计算原理与边界

`physics.js` 是实际游戏与预测器共用的物理内核。`solver.js` 对不同横坐标分别创建局面副本，推进 Matter.js 碰撞、旋转、合成与生长，按合成收益、最高堆叠、表面高差、残余运动和越线危险评分，再细化较好的位置。标准模式与深入模式会尝试有限的两步搜索。

优先在 Web Worker 中计算，避免阻塞游戏。仅使用当前盒子和界面公开的下一盒，不读取尚未生成的随机盒子。

提示是有限时间内的启发式预测，不保证全局最优或必胜。物理快照没有完整复制碰撞求解器的历史接触缓存；复杂堆叠、微小移动和后续随机盒子可能使实际结果与预测存在差别。“预计得分”不是承诺。

## 更新 GitHub Pages

将修改提交到本地 Git 后，在项目目录中运行：

```powershell
git push github HEAD:main
git subtree push --prefix dist github gh-pages
```

站点发布源为 `gh-pages` 分支的根目录。推送后需要等待 GitHub Pages 构建成功，再确认线上页面已更新。

## 文件

- `dist/index.html`：原版主界面与新增提示控件。

- `dist/hint-worker.js`：后台计算入口。
