# 游戏装饰二维码

- 扫码目标：https://zxshm.github.io/wilddog-milk-hints/
- `合成野生狗奶-装饰二维码.png`：2400 × 3040 像素，可保存、转发或打印。
- `合成野生狗奶-装饰二维码.svg`：矢量排版源文件，已内嵌游戏奶盒图片。
- 装饰采用游戏原有奶油色、橙色及 `dist/img` 奶盒素材，并加入爪印、星光和落下箭头。原奶盒素材来源沿用仓库的原作者说明。
- 由真实网址编码生成二维码，纠错等级 H，保留四格净空；没有用生成式图片模拟二维码。
- `二维码识别校验.json` 记录 ZXing 解码检查：2400、1200、600、360 像素宽图片及 600 像素宽、质量 70 的 JPEG 均识别到同一目标网址。该检查不等同于每一种手机相机或微信版本实测。

生成脚本为 `scripts/create-share-qr.cjs`，使用 Node.js 的 `sharp` 渲染 SVG，并调用 Python 的 `qrcode` 生成矩阵。可以通过 `QR_PYTHON` 指定 Python 路径，通过 `PYTHONPATH` 指定二维码依赖目录；验证使用 `zxing-cpp`。本次依赖安装在被 Git 忽略的 `output/qr-tools` 中。
